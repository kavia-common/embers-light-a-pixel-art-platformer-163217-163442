# Ember's Light — Pixel Art Platformer (Frontend)

This workspace contains the Ember React frontend.

Run the frontend:
- cd ember_frontend
- npm install
- npm start

Open http://localhost:3000

Features implemented:
- Pixel-art canvas with dynamic lighting
- Platforming physics and controls
- Light-as-life flame system with decay/regeneration
- Environmental hazards (rain, wind, darkness)
- Stealth/dimming, tactical combat (burst, seeds, ignition)
- Puzzles (mirrors/solar beams hooks)
- Upgrades, world map overlays
- Ambient audio (WebAudio) and local save/load
